# Kare

Fotoğraf ve video paylaşım sitesi. Arayüz düz HTML, CSS ve JavaScript; hesaplar, veritabanı ve dosya depolama Supabase üzerinde.

- `index.html`, `styles.css`, `app.js`: site
- `config.js`: Supabase adresi ve herkese açık (anon) anahtar. Veriyi satır güvenliği kuralları korur.

Yerelde denemek için klasörde `python3 -m http.server` çalıştırıp `http://localhost:8000` adresini aç.
